# Jean Lucas · @jeanlucasbm

Mini landing (link-in-bio) con el **Diagnóstico de Salud Digital** integrado.

- `index.html`: página completa (HTML + CSS + JS, sin dependencias ni build).
- `foto.jpg`: foto de perfil (también va incrustada en el HTML).
- `/#diagnostico` abre el test directamente.

## Despliegue en Vercel

1. Importa este repositorio en [vercel.com/new](https://vercel.com/new).
2. Framework Preset: **Other**. Sin comando de build. Output: la raíz.
3. Deploy. Cada `git push` a `main` vuelve a publicar.
